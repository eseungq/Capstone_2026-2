# ai · AI 추론 서버

담당: 김도현

이 폴더에 들어갈 것
- 추론 서버 코드 (백엔드가 호출하는 `POST /internal/v1/predict`, `GET /internal/v1/models`)
- 모델 학습·평가 스크립트, 정책 검증 자료(검증 범위·지표) 생성 방법
- 실행 방법 (필요한 환경, 모델 파일 위치, 포트)

연동 기준: [계약 v4 7장](../docs/백엔드_API계약_v4.md#7-ai-연동-규격-합의-1015)

> 실제 AI 서버가 준비되기 전에는 백엔드 개발용 [Mock AI](../backend/mock-ai/)로 같은 규격을 흉내 냅니다.
> 모델 가중치처럼 큰 파일은 저장소에 올리지 않고 받는 방법만 적어 주세요.
