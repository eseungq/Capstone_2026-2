# 공개 소스 점검 · 2026-11-26

## 확인한 범위

- Windows C 작업 폴더와 D 코드 사본의 scripts/tests는 같은 파일이며 D에만 있는 추가 소스는 없었다.
- DGX 프로젝트의 ai_api, door_experiment, frame_model, cowl_model, prototype, src와 현재 배포/보정/학습 소스의 정적 경로 의존 디렉터리를 대조했다.
- GitHub 기존 ai/에는 도어 중심 코드만 있었고, 프레임·카울커버 실제 배포 및 학습·평가 소스가 빠져 있었다.
- DGX 자체는 Git 작업 트리가 아니므로 untracked 목록 대신 파일·의존 경로·해시를 기준으로 조사했다.
- outputs의 모든 과거 실험을 무차별 공개한 것은 아니다. 생성 결과·중복 overlay·과거 무관한 준비 작업은 제외하고, 현 배포 및 수집한 소스에 명시된 경로의 직접 의존 코드를 포함했다. bumper_model은 플랫폼 대상 세 부품 밖의 초기 탐색 코드라 제외했다.

## 공개본 검증 결과

- 출처 해시 기록: 266개 소스 파일. 원본과 공개본 SHA-256을 source_manifest.json에 기록.
- Python 문법 확인: 224개 파일 통과.
- Python AST 대조: 문서화한 개인 경로·팀 주소 문자열 치환 외 코드 구조·수치 보존. 모델/보정 파라미터 변경 없음.
- 고정 토큰·개인키 패턴·실제 사진 base64 검사 및 인증정보 의심 구문 수동 검토. 테스트용 가짜 서명/자격 문자열과 실행 중 생성되는 난수 토큰은 실제 인증정보와 구분.
- 로컬 모듈 이름 기준의 from-import 의존성 목록 대조: 미포함 프로젝트 모듈 이름 없음. 이것은 모든 동적 로딩·외부 아티팩트의 완전한 독립 실행을 보장하는 검사는 아니다.
- 기존 공개본 source_manifest.json 해시 검증 통과. 처음 Windows CRLF 체크아웃에서 발생한 불일치는 이 별도 작업 사본을 Git 원본 바이트로 맞춰 해결. 기존 소스 내용 변경 없음.
- 기존 공개본 단위 테스트 7/7 통과.
- 기존 공개본 모의 HTTP 11개 검사 통과. 실제 GPU·가중치·현장 사진·백엔드 접속 시험은 아님.
- 추가 DGX 소스의 API·백엔드 계약·CAM 인코딩 모의 테스트 18/18 통과.
- 같은 테스트 모음의 실사진 디코딩 1건은 비공개 door_internal_validation.csv가 없어 최초 실행에서 FileNotFoundError. 이 항목은 공개 환경에서 미검증으로 남기고, 실사진을 요구하지 않는 18건만 분리해 재실행했다. 데이터나 빈 CSV를 만들어 우회하지 않았다.

운영 DGX 파일, 실행 중인 추론 프로세스, 가중치, 보정기, 데이터/분할/라벨, 기존 공개 서버 구현, 백엔드·모바일·DB 코드, 실제 활성 정책.

이 점검은 소스 누락 보완과 공개 안전성 점검이다. 새 모델 성능 검증·재학습·재배포 결과로 해석하지 않는다.
