# 실행 증빙과 한계

## 실제 DGX ↔ 백엔드 연결

2026-11-04, 기존 e02 서버에서 다음을 확인했습니다. 공개본을 새 서버로 배포한 결과와 혼동하지 않습니다.

- GOOD 원본 점수 0.010911530815064907, 보정 두 필드 null, Grad-CAM 없음.
- DEFECT 점수 0.9999741315841675, JPEG CAM 596,675 bytes 저장.
- Content-Length JSON 정상 처리, chunked 요청 400 문제는 백엔드 수정 후 해소.
- 미지원 모델 버전 409, 허용되지 않은 이미지 출처 422.
- 별도 시험 서버의 강제 503, 백엔드 타임아웃, 실제 컨테이너 중지 시 접속 거절.
- 컨테이너 복구 후 동일 모델 목록 HTTP 200 및 loadable=true.
- 재검사 성공 UUID와 GOOD·inferenceTimeMs 658을 AI 로그에서 대조.
- B6 실제 자연 발생 NO_ACTIVATION은 보류. 강제 JSON 형식 시험과 구분.

백엔드의 ALREADY_RETRIED·원본 FAILED 연결·목록 제외 처리는 백엔드 담당자의 공동 시험 보고입니다. AI 단독 테스트만으로 DB/앱까지 검증했다고 표기하지 않습니다.

## 공개본 단독 확인

- 기존 실행 소스에서 개인 경로/사설 주소만 환경변수화했습니다. 실제 추론·전처리·Grad-CAM 메서드는 원본과 AST가 같습니다.
- 공개본의 단독 테스트 6개 통과: 실제 loopback HTTP+Stub, JPEG 크기 유지, DEFECT 게이트, 보정 null, 지표 분모, 비정상 숫자 거부.
- Stub HTTP 시나리오 11개 통과: 모델 목록, GOOD, 생성, ZERO/CONSTANT, CAM 실패, 분류 실패, 모델 버전, 미지원 부품, 잘못된 JSON, 잘못된 경로.
- 이 테스트는 모델 가중치·실제 사진·GPU를 사용하지 않습니다. 새 공개본 전체를 실제 GPU HTTP로 재검증한 것은 아닙니다.
- 운영 DGX의 코드·가중치·CAM 방식·정책은 이번 공개 작업에서 바꾸지 않았습니다.

## 실행 환경 변경과 모델 변경의 구분

공개본의 변경은 경로·허용 출처 설정과 실행 안내, 점검 도구입니다. 입력 크기·정규화·리사이즈·분류 컷오프·가중치·CAM 수식은 바꾸지 않았습니다.
원본 run_config와 데이터 감사는 비공개 검증 프로젝트에서 계속 검사합니다. best.pt만으로 독립 실행되는 가벼운 배포 패키지는 아직 아닙니다.

28×28 HiResCAM과 JET 50%는 별도 연구 후보입니다. API의 운영 Grad-CAM은 기존 7×7 및 기존 색상 표현을 유지합니다.

## 보정 및 AUTO_PASS

`policy_readiness_audit.json`은 실제 동결 메타데이터의 준비조건 검사입니다. 정책 등록 요청 본문이 아닙니다.
보정/정책용 데이터는 각각 990장(정상 439, 불량 551)입니다. 알려진 그룹·파일 경로의 분할 간 중복은 없지만 미확인 유사 사진과 동일 실물 독립성이 해소되지 않았습니다.
`policy_development`를 사용해 기준을 고른 뒤 같은 자료의 결과를 독립적인 정책 안전성 증빙으로 제시하지 않습니다.
운영 준비 상태는 `releaseReady=false`이며 운영 보정기 버전, 보정 확률, 정책 기준치는 `null`입니다. 실제 연동에서는 `REVIEW`로 처리합니다.

표본 수만 보면, 불량 551장에서 미검출이 0이어도 고정 정책/독립 표본을 가정한 단측 95% 상한은 약 0.5422%입니다. 이는 0.5%를 보장할 수 없다는 수학적 예시일 뿐, 현 데이터의 독립성이 검증됐다는 뜻이 아닙니다.
`evaluate_policy_scores.py`는 보정된 점수가 준비됐을 때 개발 지표를 계산하는 도구이며, 정책 승인·활성화·독립 검증을 대신하지 않습니다.

### 도어 e02 캡스톤 시연 기준

2026년 11월 7일, `door-swin-tiny-e02-28a2dd1cb40b-dev`의 도어 시연 기준을 **30%**로 선정했습니다. 기존 모델이 `GOOD`으로 예측하고 실험용 보정 불량 확률이 0.30 이하이면 시연에서 `AUTO_PASS`를 표시합니다. 그 외 분석 완료 건은 `REVIEW`로 표시합니다.

CARS-AD 개발용 원본 100장으로 온도 보정값 0.6025595860743578을 적합했습니다. 최초 기준치를 고정한 뒤 별도로 둔 원본 148장(정상 62장, 불량 86장)을 평가했습니다.

| 기준 | 정상 자동 통과 | 불량 자동 통과 |
|---|---:|---:|
| 사전에 고정한 최초 기준 44.71% | 53/62 | 1/86 |
| 같은 148장에 사후 적용한 시연 기준 30% | 53/62 | 0/86 |

30% 결과는 동일 자료의 사후 비교입니다. 평가 단위는 사진 그룹이며, 실제 부품 식별자는 확인하지 못했습니다. 최초 평가의 불량 통과 1건은 원본과 정답 마스크를 대조해 확인했습니다. 시연 결정과 오프라인 증빙 해시는 audit의 `capstoneDemoDecision`에 기록했습니다. audit 최상위 필드에는 기존 운영 준비 상태와 메타데이터 감사 범위가 담겨 있습니다.
